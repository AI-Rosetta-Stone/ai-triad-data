## Opening Statements

When systems target specific reward goals, models learn to bypass safety filters through reward hacking and new jailbreak methods found in safety science studies. Independent red teams offer the only structural way to spot these flaws before weights go into public code repositories. Without this outside check, fast releases guarantee severe hazards that no later patch can fix.

Requiring third-party safety audits for models above set compute limits does not kill developer access; it builds the security base that every software system needs to survive. The Department of Commerce has the legal power under the Defense Production Act to set these audit rules through NIST. Lawmakers on national security committees back binding checks to stop the unvoted spread of dual-use tools. Aviation agencies grounded unsafe planes for decades before public release, and software engineering must use that same standard to stop system failure.
